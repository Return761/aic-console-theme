# AIC 控制台主题

面向 DSH NEXT 的工程控制台主题。中性面板、空心几何、细刻度与有来源的动态辉光，让信息和操作保持清晰。

当前版本 **0.9.3**。通过宿主 Client token、样式和可回收插槽扩展界面。

## 功能

- **三套配色与深浅模式**：青绿/砂金、赤红/砂金、灰紫/冰蓝；赤红主色为 `#AA2827`。
- **工程制图首页**：四层半透明空心菱形、鼠标视差、点击波纹、四边标尺、折角和空心三角。
- **动态输入栏**：8px 方角银色循环光带、可自定义标题、会话标识和真实状态。
- **Agent 启停视觉**：全屏通知及底部运行光带；待机灰色，运行时跟随第一主题色。
- **运算深度**：取当前模型支持的实际推理等级，逐格扫描，支持键盘与减少动态。
- **可开关布局**：项目树、会话记录、轮次轴、活动终端、任务/目标、余额、状态条及消息居中。
- **账号余额**：复用当前登录账号，无须为主题另填 Key；失败和不可用有独立状态。
- **加载页**：白色空心菱形、初始化节点日志与完成动画；可选择按键或点击后进入。

## 安装

```sh
git clone https://github.com/Return761/aic-console-theme.git
```

在 DSH 插件管理器提供的本地插件安装/链接入口中选择克隆目录，启用主题并刷新。仓库包含已构建客户端和字体分包，直接使用不需要先运行 npm。建议先停用其他覆盖相同界面的主题。

完整说明：[安装与开发](docs/installation.md)。本项目尚未发布到 npm 注册表。

## 字体

| 用途 | 字体 | 提供方式 |
| --- | --- | --- |
| 正文、中文与常规控件 | HarmonyOS Sans SC | 原始 Regular / Medium / Bold 随插件分包提供 |
| 日志、路径和技术标记 | JetBrains Mono | 随插件提供 |
| 大数字 | Bahnschrift | 使用系统已安装字体 |
| 品牌与启停诊断栏 | Rajdhani | 随插件提供 |

本软件使用 HarmonyOS Sans SC，Copyright 2021 Huawei Device Co., Ltd.。字体保持原始 TTF，不裁字或转换格式；缺少本地字体时从插件加载。完整中文字库会增加包体，字体分包未塞进启动主脚本。

第三方许可见 [NOTICE.md](NOTICE.md)；实现及字节校验见 [字体嵌入说明](docs/harmony-font-embedding.md)。

## 开发与验证

```sh
npm ci
npm run build
npm run check
npm test
```

Node.js 24。编辑 `src/` 后构建，勿手改生成的客户端文件。当前包含 **41 项单元测试**；实际 DSH NEXT 界面已检查六种视口以及深浅模式。CI 负责离线构建和测试，不启动真实 Agent。

视觉约定：[设计系统](docs/design-system.md)。

## 兼容与数据

- 当前界面结构在 DSH NEXT 2.0.22-next / DSH 0.2.2-rc.1 上检查；宿主升级后可能需要适配选择器或插槽。
- 遥测只统计已加载记录，余额和任务投影以宿主实际能力为准。
- 光条是装饰和状态反馈，不代表任务进度；启停预览不会启动或停止 Agent。
- 主题不修改 DSH 安装归档。禁用时回收自有样式、监听器、插槽和字体注册。
- 私有参考图、真实会话截图、认证链接及本机诊断资料不随仓库公开。
