# AIC 宣传片拍摄包

目标：60 秒、16:9 的产品介绍。工程制图感、空心几何、银色扫描和主色运行光带构成视觉主线，节奏由安静到启动，再回到片尾的秩序感。

仓库：[Return761/aic-console-theme](https://github.com/Return761/aic-console-theme)。本包是拍摄准备与可录素材排练，不是已剪辑影片。

## 交付文件

- [分镜、口播与声音设计](storyboard.md)：逐秒安排、操作和转场。
- [中文字幕 SRT](narration.zh-CN.srt)：60 秒时间轴，可直接导入剪辑软件；录音后按实际语速微调。
- [拍摄与导出清单](recording-checklist.md)：真实宿主素材、隐私检查、画面规格。
- [离线排练页源码](../../tools/promo/index.html)：五个镜头状态、三套配色、深浅模式、启停光带预览。

## 开始排练

在仓库根目录运行，Node.js 24，无需 DSH、账号或网络：

```sh
npm run promo:preview
```

浏览器打开终端显示的本地地址。默认只监听 `127.0.0.1:4173`，占用时可运行 `npm run promo:preview -- --port 4174`。按 F 全屏，再按 H 隐藏控制面板；H 可恢复。停止服务用 Ctrl+C。

| 按键 | 操作 |
| --- | --- |
| 1–5 | 菱形首页 / 输入栏 / 三套配色 / 运行光带 / 片尾 |
| P | 青绿 → 赤红 → 灰紫 |
| L | 深浅模式 |
| R | 运行光带与输入状态的视觉预览 |
| M | 开关动态效果 |
| F / H | 全屏 / 隐藏控制面板 |
| 鼠标移动 / 点击背景 | 菱形视差 / 单次波纹 |

排练页直接加载当前 `src/` 中的菱形 GPU/Canvas 实现、输入栏组件、配色和相应样式。它只提供构图和可复拍的视觉素材，**不是 DSH 完整界面**；保留“视觉演示 / 未连接 Agent”标识。运算深度在排练页只有文字位置说明，实际控件、加载页、侧栏、轮次轴和设置操作须从真实 DSH 录制。

排练页不调用模型、不请求余额、不读取真实会话，也不模拟工具数量、任务完成或模型进度。运行状态只驱动视觉演示，不能作为真实 Agent 执行画面。

## 一次生成构图参考

```sh
npm ci
npm run promo:capture
```

使用本机 Chrome 或 Edge；其他路径通过 `CHROME_PATH` 指定。生成 1920×1080 的构图参考、拼版和检查结果到 `.artifacts/promo/`，不会上传真实宿主截图。脚本会核对菱形、输入光条尺寸、六种配色/模式、状态色和资源隔离。

录制前等字体加载完成，所有字体从本地原始文件加载；Bahnschrift 使用系统字体。录屏建议在剪辑时放大局部，而不是将原始 8px 光条改粗。
