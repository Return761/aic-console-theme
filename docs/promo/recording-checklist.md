# 拍摄检查清单

## 工作台

- [ ] 录制单独窗口或屏幕，1920×1080 或 2560×1440 / 60fps；浏览器缩放 100%，关闭通知和会抢焦点的程序。
- [ ] 使用单独的 DSH 演示配置/工作区。项目名可用 `AIC.Demo`、`Signal.Lab`；隐藏真实头像、手机号、磁盘路径、真实对话、认证地址和账单。
- [ ] 不把带认证参数的浏览器地址栏录进去；不要在真实账号页面临时打开调试控制台。
- [ ] 余额组件使用真实不可用状态或直接关闭，不能为了宣传填一个“成功获取”的虚构数值。活动计数与任务记录也不造数。
- [ ] 主题版本、配色、密度、标题、动效开关在每条素材间保持可复现。等本地字体加载完再录。
- [ ] 首轮使用普通动态模式拍摄；另保留减少动态的静态参考，不宣称未经测量的帧率。

## 可复拍镜头

- [ ] 加载：实际初始化 → 日志 → 完成上抬 → 进入。启用“完成后按键进入”可留足拍摄余量；录完恢复偏好。
- [ ] 首页：先静止 2 秒，再缓慢横移鼠标，再单击一次；波纹未退尽不要连续点击。
- [ ] 输入条：录至少 8 秒获得完整银色循环；焦点不会出现异常红框，空心菱形无遮挡。
- [ ] 配色：深色三套各录 5 秒，浅色至少录一套 5 秒；中性面板一致，赤红为 `#AA2827`。
- [ ] 运算深度：只选模型实际支持的等级，录键盘/鼠标调节；保留逐格扫描和清晰文字，拍摄不调用模型。
- [ ] 信息模块：准备有足够演示内容的侧栏和轮次轴；依次切换，不展示真实用户资料。
- [ ] 启停：使用主题自己的视觉预览入口；画面保留“预览”标识。不要为了拍光带触发付费 Agent 运行。
- [ ] 片尾：地址清晰可读，停留至少 3 秒；源码公开和代码授权区别按 README 表述。

## 后期与发布

- [ ] 所有近景都来自实拍或明确标注的视觉演示。离线排练页只用于几何、光带、配色及片尾素材。
- [ ] 检查右侧轮次、侧栏开关、标题行、弹出菜单是否错位；不裁剪掩盖明显界面错误。
- [ ] 字幕不覆盖运行光源、输入条与右侧刻度；手机预览下仍可读。
- [ ] 音乐、音效、字体保留所需许可或署名；不把原始参考图当宣传片素材。
- [ ] 逐帧检查账号、文件路径和地址栏；无真实会话记录，无认证信息，无旧品牌数字。
- [ ] 导出带字幕版、无字幕母版、SRT、封面，检查开头结尾黑帧与音频爆音。
- [ ] 发布简介放仓库链接与兼容版本；本次仅准备拍摄，尚未向视频平台发布。
