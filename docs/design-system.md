# 视觉与交互约定

本主题采用中性工程控制台界面：细线分区、清晰边界、紧凑排版、空心几何标识和局部光源。

## 字体

| 角色 | 字体 |
| --- | --- |
| 常规内容、中文、按钮与说明 | HarmonyOS Sans SC |
| 日志、路径、ID、技术标记 | JetBrains Mono |
| 独立大数字 | Bahnschrift |
| 品牌字标及启停诊断栏 | Rajdhani |

HarmonyOS Sans SC、JetBrains Mono、Rajdhani 随插件提供；Bahnschrift 使用系统字体。字体许可见根目录 NOTICE.md。

## 颜色

- 三组第一/第二主题色：青绿/砂金、赤红/砂金、灰紫/冰蓝。
- 赤红主色固定为 `#AA2827`；深浅模式分别调整其他强调色的可读性。
- 面板、文字、边框保持中性，换配色不把整块背景染色。
- 第二主题色用于空心菱形及标识，不作为发光色。
- Agent 底部光带待机灰色，运行时使用当前第一主题色；亮芯向近场、远场逐级衰减。
- 输入栏内的 8px 方角光条始终为银色循环光源。渐变表达光源延伸，不作无来源的装饰渐变。

## 核心组件

- 首页采用四层连续半透明空心菱形；默认共心，鼠标移动时分层缓动，离开后回归。四边镜像刻度、跟随鼠标的三角、四角折线和空心三角组成图框。
- 标题与控件共享基线；页签、更多入口及右侧标语各占明确空间。窄屏优先折叠辅助信息。
- 用户消息居中可开关，关闭后恢复宿主对齐；正文保持正常阅读排版。
- 顶部模块开关激活时为实心色块，关闭时为线框。
- 运算深度取当前模型真正支持的等级。逐格扫描，轨道不整体发光，不增加虚构等级。
- 项目、对话列表、轮次轴、终端、任务/目标、余额等模块可分别控制。
- 余额复用宿主当前登录账号，不新增 Key 输入；失败和不可用均有独立状态。

## 动态与性能

首页在支持时使用单次 WebGL 绘制，静止后停止请求帧；不可用时回退缓存画布。点击反馈数量有上限。离开页面后回收资源。

持续动态开关和系统“减少动态”均受尊重。加载完成等待确认是独立交互选项：开启后可按键或点击继续，并消费触发输入以避免穿透。

启停预览仅演示视觉效果，不启动或停止实际 Agent。加载日志表示插件初始化阶段，输入栏光条不表示任务进度，遥测只统计已加载记录。
